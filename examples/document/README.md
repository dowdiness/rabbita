# Counter

A minimal Rabbita counter example.

## Run in development

In this directory:

```sh
moon install moonbit-community/warren
warren dev
```

Then open the local URL shown by warren.

## Run the native server

Build the browser bundle first, then run:

```sh
moon run main/main.mbt --target native
```

The server listens on <http://127.0.0.1:3000>.
